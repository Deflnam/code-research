# Code Research

Приложение для исследования свойств помехоустойчивого кодирования
в режиме обнаружения ошибок.

## Что делает
- Имитирует передачу данных по каналу с шумом (БСК).
- Кодирует данные с помощью CRC (CRC-32, CRC-16).
- Обнаруживает ошибки.
- Собирает статистику: P_обн, P_проп.

## Структура
- `cmd/app/main.go` — точка входа (CLI).
- `internal/channel/` — модель БСК.
